# prd-skill

A tracker-agnostic agent skill for writing PRDs and splitting them into tickets an autonomous coding agent can take from spec to PR.

Forked from [snarktank/ralph `skills/prd`](https://github.com/snarktank/ralph/blob/main/skills/prd/SKILL.md) (MIT). Keeps Ralph's structure and adds one-slice-per-job tickets, verifiable acceptance checks, and a spec→PR definition of done. Works with Plane, Linear, GitHub Issues, or plain markdown.

## Install

Copy `skills/prd/` into your agent's skills directory (e.g. `.agents/skills/prd/`).
